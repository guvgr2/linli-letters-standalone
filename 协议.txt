OliviaSoul-community独立版 · 使用协议

请先读完这一段。它不长，说的都是跟你有关的事。

一、你的东西都在你自己机器上
    信件、设置、账本、曲库索引，全部存在本机（数据目录：%APPDATA%\LinliLetters）。
    这个程序本身不收集、不上传、不分析你的任何内容。没有账号，没有云同步，没有遥测。
    ★ 会离开这台机器的只有两件事，都在第二条写明：
      ① 回信 —— 那封信的内容发给你自己选的那家模型厂商；
      ② 检查更新 —— 只有你点了「检查更新」才会去 GitHub 读一次发布列表，不带任何本机信息。
      除此之外，程序不会自己往外发任何请求。

二、会发出去的，只有你自己写的那封信和你自己填的那把钥匙
    写信要调用大模型。这个程序只做一件事：把你填进设置页的那把 Key，
    原样发给你自己选的那个厂商（OpenAI / DeepSeek / 月之暗面 等）的官方接口。
    我们不中转、不代持、不代充、不做任何支付。Key 用 Windows 的 DPAPI
    按当前用户加密后存在本机，不写进日志。

    ★ 这把 Key 什么时候会出门，一共三个时刻，每一个都要你自己按下按钮：
      · 点「保存并测试」—— 发一句「只回复 OK」过去，看通不通；
      · 点「查询模型列表」—— 去那一家读一次它的模型清单（它要看到 Key 才肯给这份清单）；
      · 真的写信 —— 你写的正文、最近几封往来、以及跨封记忆账本一起发过去，
        由那家厂商按它自己的隐私政策处理。
      这个程序本身不中转、不代持、不留存副本。
      不填 Key 就不会发出任何内容 —— 写信会停，程序照常能开。
    你随时可以在设置页删掉它 —— 删了之后写信会停，程序照常开。

三、没有钱的事
    这个程序里不存在充值、余额、商店、道具、付费徽章。它是免费的非商业项目。
    本程序自己不向你收任何费用。但你填了模型 API Key 之后，回信要付的
    模型调用费由你选的服务方按量计收，那是你和那一家之间的事，
    本程序不经手这笔钱，也不知道你花了多少。
    设置页顶上如果显示一个余额，那是读的你「你自己那个厂商账户」里剩多少，
    跟我们没有关系；读不到就显示「—」。

    安装包里只有这个程序自己的代码与两个内置的运行时。
    两个运行时分别是 Node.js（v22，跑写信与本地服务）与 .NET 运行时（跑程序外壳），

    我们这边没有预置任何信件正文，也不代你写、不内置剧本。
