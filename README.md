# OliviaSoul-community独立版

**当前版本：1.0.0**

一个完全本机的写信程序。你写给她，她回给你；有时候她也会先写。

它**不是** OliviaSoul 的插件，也不依赖任何游戏本体 —— 这是从零起的一个独立程序。

---

## 它是什么

- **不联网也能用**：除了调用你自己填的模型接口生成回信，其余全在本机。
- **没有账号、不上传、不扣费**：信件和记忆都在这台机器上，一个 SQLite 文件里。
- **API Key 用 Windows DPAPI 按当前用户加密**：不写日志、不进任何导出包。换 Windows 用户或换机器后解不开，届时需要重新填一次（这是预期行为）。
- **界面是液态玻璃**：中性白柔光 + 半透明玻璃面 + 斜向反射带 + 微光晕 + 顶部高光。排布对齐原版：信箱是「左列表 + 右阅读区 + 左下写信条」，曲库是「分类页签 + 曲目表 + 音乐桌面歌单 + 底部播放条」，四个页签是 古典 / ACG / 轻音乐 / 我的上传。
- **桌面壁纸层**：把曲库里的视频铺到 Windows 桌面那一层（在图标底下），按当前时段换变体，桌面上留两个圆钮（音乐 / 信箱）能直接叫出程序。曲库是空的就一点都不动你的桌面。

## 怎么用

1. 双击 exe 先出一屏**启动动画**（纸质动画：开盖 → 抽信纸 → 摊开 → 落墨 → 盖火漆印 → 折纸飞机 → 飞向远方）。动画在放的同时，后台跑「预检 → 起内置运行时 → 探健康」三步，每步通过动画推进一拍，三步都过了才出主窗口。之后托盘里出现图标，界面是**程序自己的窗口**（无边框 + WebView2，不是浏览器窗口）；曲库里有曲子的话，桌面上还会多出一层按时段换的壁纸。
2. 第一次进 **设置 → 模型**，填接口地址和 API Key，点「测试连通性」。
3. 回 **信箱** 写第一句，寄出。等她回信。

## 关于「她先写」

这个功能**默认开启**（第一次打开时会问一次，可随时在设置里关掉）。开启后，她只会在下面这些条件全部满足时写一封：

| 条件 | 默认值 |
|---|---|
| 可打扰时段 | 09:00 – 21:30 |
| 距上一封往来至少 | 20 小时 |
| 24 小时内最多 | 1 封 |
| 7 天内最多 | 4 封 |
| 没读的主动信 | 攒到 2 封就先停；越攒等得越久，最长 7 天后仍会恢复，不是永久停 |
| 不能有其他信在生成中 | 是 |
| 至少要有一封已有往来 | 是 |

这些数字都能在设置里改。判定原则是**宁可不发** —— 任何一个条件不满足就跳过。

三条硬边界：

1. **不伪造用户发言。** 她先写的信没有任何「来信」，触发只来自程序这侧能观测到的事：你刚听完一首歌、整理时发现什么、你们有多久没往来、或者只是一个平常的下午。
2. **不推进关系。** 她先写的信不写新的情感、称呼或亲密动作。跨封账本只认她**已经发出的回信**，不认来信人的愿望、自称或单方面升级。
3. **不把设想当事实。** 记忆分两栏：「已成立的共同事实」和「未决」。你说「想学吉他」，它进的是未决，不会在几封信之后变成「你现在练得怎么样了」。

## 曲库

曲库是你机器上**自己的**一个目录（默认 `E:\linlimusic`）。这只是初始值 —— **可以在「设置 → 曲库目录」里改成别的目录**，改完重新扫一次即可。程序只指向它 —— 不复制、不随包、不改里面的文件。扫进来的曲目分四档，页签就是这四档：

| 页签 | 这一版实测（E:\linlimusic） |
|---|---|
| 古典 | 48 |
| ACG | 68 |
| 轻音乐 | 13 |
| 我的上传 | 2455 |

- **档位是程序分的，不是你选的。** 第一次扫描到某个曲目目录时就把档分完，结果记进 `letters.sqlite` 的 `song_genres` 表；之后再扫，分过的不动，只补新出现的（这是一条幂等操作，所以每次扫描都可以放心调）。判据在 `app/core.mjs` 的 `classifyGenre`，顺序即优先级：先认「我的上传」（`midi_` / `oliviasoul_` 开头是你自己传上去的那批）→ 再查对过表的那 129 首（**这是真值**，表内的曲子不再走关键词，所以「克罗地亚狂想曲」不会被 `rhapsody` 抢进古典那一档）→ 表外才轮到关键词（作曲家与曲式 → 古典，日系与 Hoyo → ACG）→ 都认不出就兜底轻音乐。
- **判据只吃目录名和曲名**，不联网、不读任何元数据文件。曲库就是本机的一堆文件夹，没有别的地方可查，也不需要查 —— 依赖元数据就等于把「能不能听」押在曲库目录的完整性上。
- **哪些目录算曲目**：`solo` / `playsing` / `midi` / `oliviasoul` 开头的。前两个是原版那批，后两个是「我的上传」这一档（原版右栏写的「个人上传 · mid_11565_…」也是它们）—— 不把后两个算进来的话，这一档永远是空的，等于摆了个点不动的按钮。
- **曲目表的「模式」列**是 `独奏 / 弹唱 / 个人上传`，跟分档同一套命名口径。原版写的是**弹唱**不是「演唱」，PlaySing 那批本来也是边弹边唱，照它的字。
- **时段不给用户选。** 白天 / 傍晚 / 夜晚由服务端按本机时钟判（`playbackTimeOfDay`）：06:00–16:00 白天、16:00–20:00 傍晚、20:00–06:00 夜晚，只用于挑桌面壁纸层的变体。界面上不摆这个开关 —— 摆了就得回答「为什么我现在选不了夜晚」，而答案是「因为现在是下午」，这个问题本身没有意义。
- **界面上没有「把这首改到另一档」的入口。** 分错了是判据的错，应该去改判据；给用户一个手改的口子，等于把「程序分得不准」这件事藏起来。

## 数据在哪

```
%APPDATA%\LinliLetters\letters.sqlite
```

卸载不会删这个目录 —— 你的信还在。想彻底清掉，连这个目录一起删。

## 目录结构

```

  import-session.mjs   预览登记簿与 30 分钟有效期（预览只在内存里）
  db-import-columns.mjs  导入要用的两列（content_md5 / archived_at），幂等补列
  public/         液态玻璃界面（splash.html 是启动动画那一屏）

  SplashWindow.cs  启动动画窗口（双击 exe 后先出来的那个）
runtime/node/   内置 Node 运行时（node.exe 与它的 LICENSE，两个文件）
installer/frames/  安装动画的 48 帧（dontcopy：只随包走，不落到 {app}）
tests/          护栏测试（node --test --test-force-exit tests\ 下全部）
  error-codes.test.js  错误号的出口覆盖与「号 ↔ 错误号一览.md」双向校验
  import-route.test.js 导入的端到端：起真服务、发真 HTTP、落真库、直读对账
```

## 打包

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1
```

需要 .NET 10 SDK 与 Inno Setup 6。产物是 `dist\` 下的安装程序（以实际产物为准；打包脚本会自己拒绝把任何 `.ttf/.otf` 装进包）。

安装向导会播一套纸质动画：开盖 → 抽信纸 → 摊开 → 落墨写「—— 林离」→ 盖火漆印「离」→ 折纸飞机 → 飞向远方，半路变玻璃飞机。做法是 48 帧 `installer/frames/*.png` 以 `dontcopy` 带在包里，`[Code]` 里用 `SetTimer` 每 156ms 往向导图位贴一张 —— 帧间隔取 7500ms / 48 ≈ 156ms，跟 `design-preview-安装动画.gif` 一个速度。走 `dontcopy` 是因为这些帧只在装的这几分钟用得上，装完就该跟着 `{tmp}` 一起没掉，不该留在 `{app}` 里占位。代价是安装包多约 2.5 MB，换安装过程不是干等着。<!-- 待实测：安装动画帧带来的实际增量 -->

## 出错时看哪里

程序里每一处会失败的地方都带一个**报错号**：界面上弹的那句话末尾有全角括号包着的号（如「信是空的（LETTER_EMPTY）」），响应 JSON 里另有一个纯号字段 `code`（给程序、脚本、日志认）。

- **号长什么样**：`域_具体事`，全大写，域有 9 个 —— `COMMON`（请求本身的问题）/ `LETTER` / `LIBRARY` / `IDLE` / `FONT` / `IMPORT`（导入旧程序的 `.soul` 归档）/ `PROACTIVE` / `MODEL` / `REPLY`。域看方向，后面看具体事，不需要查表也能读个大概。
- **每个号是什么意思、你该做什么**：见 [`错误号一览.md`](错误号一览.md)，逐号一行。
- **号是对外契约，改名等于破坏性变更**：改号必须同时改代码、改文档、改测试；`tests/error-codes.test.js` 第 ⑧ 条会把「表里有、文档里没有」和「文档里有、表里没有」都判红，所以改完不会悄悄漂。
- **四条路由故意不进这套体系**：favicon、`public/` 静态文件、`/api/media`、`/api/idle/video|ambience`。它们要支持 HTTP Range 边下边播、响应体是二进制，出错表现为「画面/声音不出来」而不是弹话，套 JSON 反而会把播放弄坏。
- **主动信生成失败时**号不弹提示，而是写在那封失败信的红字里（`letters.error`），因为那是后台跑出来的，你不在跟前。

## 说明

- 桌面快捷方式**直接指向 exe**，不经任何 .bat / .vbs / .ps1 中转 —— 中转脚本会被安全软件当成可疑启动项拦掉，图标点了没反应。
- **启动动画至少放 1.6 秒、最多 6 秒。** 下限是因为再快就等于闪一下，等于没有；上限是因为超过这个时长，用户会以为程序卡住了 —— 启动动画是让人知道「它在动」，不是让人多等。**开机自启（`--startup`）不放动画**，那条路只进托盘、没人看着，动画没有意义。
- 界面靠 `backdrop-filter` 做玻璃质感，所以必须有 WebView2 Runtime。没有 WebView2 Runtime 时会退回默认浏览器，功能一样，只是没有独立窗口。
- **程序不含任何字体文件。** 三档字迹各归各位：
  | 哪一档 | 用什么字 | 从哪来 |
  |---|---|---|
  | 程序界面（按钮、说明、列表） | **系统界面字体**（`--ui`：微软雅黑 UI / 苹方 / system-ui） | 系统自带，**不用下载** |
  | 林离写的信（读信正文、她的回信） | **SentyTEA** 汉仪新蒂下午茶体 | 你自己去官网下、自己导入 |
  | 你自己写信（输入框、以及你写的那封信） | **HanyiSentyGarden** 漢儀新蒂花園體 | 同上，另一支 |

  两支的权利都归汉仪字库，本项目不主张任何权利；都没装就退回系统楷体，界面照常。
  （原版游戏就是这两支，见 `assets/index-9ba3e01a.css` 里那两条 `@font-face`。）
- 生成回信要走你自己的模型接口，会产生费用，费用归你的接口账户，本程序不代收任何费用。
